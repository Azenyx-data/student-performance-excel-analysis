# student-performance-excel-analysis
Analysis of student performance data using Excel, including data cleaning, validation, KPI calculations, and performance insights.

Student Performance Analysis

## Project Overview

This project analyzes student performance data to understand academic outcomes and identify patterns in student results.

The project demonstrates the process of taking raw data, cleaning and validating it, and using Microsoft Excel to perform analysis and generate key performance indicators (KPIs).

## Dataset

The dataset was obtained from Kaggle and contains information about student performance and related characteristics.

The complete analysis is contained in a single Excel workbook, with separate worksheets for the raw data, cleaned data, and analysis.

## Objectives

The main objectives of this project are to:

- Measure overall student performance
- Determine the number of students who passed and failed
- Calculate pass and failure rates
- Compare performance across relevant student groups
- Identify patterns in student outcomes
- Generate meaningful insights from the data

## Workbook Structure

The Excel workbook contains three main worksheets:

1. Raw Data

Contains the original dataset obtained from Kaggle before any modifications were made.

2. Clean Data

Contains the final cleaned and validated dataset used for the analysis.

Data preparation involved identifying and correcting data quality issues, standardizing values, and validating the dataset.

3. Analysis

Contains the calculations and analysis performed using the cleaned dataset.

## This worksheet includes:

- KPI calculations
- Number of students who passed
- Number of students who failed
- Pass rate
- Failure rate
- Student group comparisons
- Other relevant performance metrics

## Key Performance Indicators (KPIs)

The analysis includes KPIs such as:

KPI| Description
Total Students| Total number of students analyzed
Passed Students| Number of students who met the defined pass criteria
Failed Students| Number of students who did not meet the defined pass criteria
Pass Rate| Percentage of students who passed
Failure Rate| Percentage of students who failed
